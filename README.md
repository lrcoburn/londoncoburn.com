Simple static site for londoncoburn.com

What's included
- index.html: single-page responsive site (Hero, Projects, About, Contact)
- styles/styles.css: plain CSS with your teal + purple palette

How to preview locally
1. Open index.html in your browser directly, or use a minimal static server:
   - Python 3: python -m http.server 8000
   - Node (serve): npx serve .

Deployment
- GitHub Pages: Enable Pages in repo settings and set the site to build from the main branch (root).
- Vercel: Import the repository and set the framework to "Other" or "Static Site". The default build command can be left empty; Vercel will serve static files.
