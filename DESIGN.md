# Visual & UX Design Guidelines (Fine Art E-Commerce)

## 1. Aesthetic Direction
- **Vibe:** Luxury editorial, high-end fine art gallery, timeless, cinematic.
- **Goal:** Avoid generic "AI tech" aesthetics (no neon gradients, no glow effects, no rounded pill badges, no default Inter-only typography).
- **Inspiration:** High-fashion luxury brand sites, fine-art portrait galleries, high-end print lookbooks.

## 2. Color System
- Primary Background: #0F0E0C (Warm Dark Charcoal)
- Card / Panel Background: #181715 (Elevated Dark Surface)
- Primary Text: #F0EFEA (Soft Off-White)
- Muted Text: #9A988F (Warm Neutral Grey)
- Accent / Highlights: #C49A45 (Muted Antique Gold)
- Border / Dividers: #2A2824 (Subtle Warm Border, 1px max)

## 3. Typography
- **Display / Headings:** Serif font (e.g., Cormorant Garamond, Playfair Display)
  - Styling: Semi-bold, tight line height, generous tracking (letter spacing) on uppercase section labels.
- **Body / Interface:** Clean Sans-Serif (e.g., Plus Jakarta Sans, Geist Sans)
  - Styling: Regular weight, relaxed line height for readability.

## 4. UI Component Rules
- **Buttons:** Sharp or subtly rounded corners (max radius 2px-4px). Solid background with high-contrast text, no heavy gradients.
- **Image Cards:** Framed look with fine subtle borders. Generous aspect-ratio containers (4:5 or 3:4 aspect ratio for vertical portrait photography).
- **Price Tags & Buy Triggers:** Elegant inline placement, e.g., "Framed Print · $500". Avoid bright green or aggressive discount tags.
- **Animations:** Subtle smooth fade-ins and slow zooms on hover (duration 300ms-500ms, ease-in-out).

## 5. Page Layout Architecture
- **Hero Section:** Full-bleed dark backdrop, large headline in serif, high-impact background or featured art piece, clear single call-to-action button ("Explore Gallery").
- **Portfolio Grid:** Asymmetrical masonry or 2-column luxury layout with ample padding around each image.
- **Artwork Detail View:** Split layout—left side sticky hi-res art viewer, right side artwork narrative, print specifications, and checkout option.
